# nft-scratch

🎬 Real-world composition scripts and examples for [my-nft-gen](https://github.com/john-paul-ruf/my-nft-gen)

This repository contains practical usage examples, composition scripts, and asset collections that demonstrate the full capabilities of the my-nft-gen generative loop engine.

---

## 📋 Available Scripts

### Core Generation Scripts
- **`npm run red-eye`** - Classic red eye effect generation
- **`npm run fuzz-flare`** - Fuzz flare composition examples
- **`npm run cosmic-jewel`** - Cosmic jewel animated loops

### Advanced Compositions
- **`npm run key-frame`** - Keyframe-based animations
- **`npm run operator-override`** - Custom operator overrides
- **`npm run red-eye-reduction`** - Red eye reduction techniques
- **`npm run curved-red-eye-reduction`** - Curved red eye variations

### Utility Scripts
- **`npm run resume-folder`** - Resume interrupted generation processes

---

## 🎨 Asset Collections

### Image Overlays (`src/assets/imageOverlay/`)
- **Original Artwork**: Hand-crafted overlay images (HocusPocus, pulse-beacon, sweet-seduction, etc.)
- **Generated Eyes**: AI-generated eye variations for overlay effects
- **Themed Collections**: Alien, bird, and cyber-eye variants

### Mapped Frames (`src/assets/mappedFrames/`)
- **All-Seeing Collection**: Mystical eye-themed frame sequences
- **Bright Collection**: High-contrast luminous frame sets
- **Halloween Collection**: Seasonal horror-themed upscaled frames
- **Flux Collections**: Eye-flux variations (OG and other-eye variants)
- **Pumpkin Collection**: Halloween pumpkin-themed sequences

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run a Sample Composition**:
   ```bash
   npm run cosmic-jewel
   ```

3. **Explore Advanced Effects**:
   ```bash
   npm run key-frame
   ```

## 📖 Learning from Examples

Each script in `src/composition-scripts/` demonstrates different aspects of my-nft-gen:

- **Effect Layering**: How to combine primary, secondary, and final effects
- **Color Scheme Management**: Dynamic color palette generation
- **Asset Integration**: Using image overlays and mapped frame sequences
- **Animation Timing**: Multi-step definitions and keyframe control
- **Performance Optimization**: Worker thread management and resource pooling
